# PRODUCT SPEC

## Product
VAJRA AI — "Let AI work. Never let it overstep."

## Goal
Provide an execution-time security gateway for AI agents by enforcing task-scoped permissions before protected tool calls execute.

## MVP in this repository state
- Monorepo structure
- Starter backend/mobile/dashboard apps
- Shared schema contracts
- Baseline CI and developer setup docs

## Not in scope yet
- Full policy engine
- Production-grade authz and approvals workflows
- Real attack simulation and forensic pipelines

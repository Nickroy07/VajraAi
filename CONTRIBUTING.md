# Contributing to VAJRA AI

## Branching
- `main`: stable demo-ready branch.
- `develop`: integration branch.
- Feature work branches from `develop` and goes through PR review.

## Pull Requests
1. Keep PRs focused and small.
2. Include validation output (tests/build/typecheck).
3. Do not include credentials or local database files.

## Security Scope (Current)
This repository currently contains scaffold implementations only. Do not represent current code as full runtime protection.
